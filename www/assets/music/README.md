# Папка для музыкальных файлов

## Куда положить музыку

Положите ваши музыкальные файлы **прямо в эту папку** (`assets/music/`).

## Поддерживаемые форматы

- **MP3** (рекомендуется)
- **M4A**
- **AAC**
- **WAV**
- **OGG**

## Пример структуры

```
assets/music/
├── song1.mp3
├── song2.mp3
├── album_track1.mp3
└── ...
```

## Важно

1. **Имена файлов** - используйте латинские буквы и цифры (без пробелов и спецсимволов)
   - ✅ Хорошо: `tokyo_drift.mp3`, `song1.mp3`
   - ❌ Плохо: `Tokyo Drift!.mp3`, `песня 1.mp3`

2. **После добавления файлов** нужно перезапустить приложение:
   ```bash
   flutter run
   ```

3. Файлы будут доступны в приложении автоматически.

## Как это работает

Приложение автоматически найдет все файлы в этой папке и добавит их в библиотеку музыки.
